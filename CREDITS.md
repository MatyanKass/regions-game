## Sound effects

None to credit: every effect is synthesised in code at startup by
[src/ui/sfx.gd](src/ui/sfx.gd) - a pitch sweep, a voice and a decay envelope each.

## Code and art

Everything else in this repository is original. The building glyphs, the map, the app
icon and the interface are all drawn with line primitives at runtime rather than loaded
from image files.
