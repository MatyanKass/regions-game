# Regions

Мобильная игра.

Клеточная 2D-стратегия в стиле «тетрадка в клетку» / морской бой.
Играешь за правителя государства: строишь заводы, жильё, банки, казармы и военные базы, копишь монеты и очки силы, захватываешь клетки. Онлайн через одну сеть.

Дизайн-документ: [Игра Regions.md](Игра%20Regions.md)

- Полная партия — ~1–1.5 часа + судный день(15-30 минут)
- MVP — 15–20 минут, до последнего оставшегося государства
