# Music

Drop `.ogg` files here and the game picks them up on the next start, no code change:

    calm/     played while the two territories are still apart
    combat/   played from the moment they touch, crossfaded in over about 1.5 s

Several files in a folder are fine - one is chosen at random and the next one starts
when it ends. Empty folders mean silence, which is a valid state.

Only tracks that are free to use commercially without attribution obligations we cannot
meet. Pixabay Music, OpenGameArt (CC0) and Incompetech (CC-BY, requires crediting the
author in-game) are the intended sources. What is in here now is listed in
[CREDITS.md](../../CREDITS.md).
